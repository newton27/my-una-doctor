Diagnose first. Repair only when the evidence is clear.

My UNA Doctor is a Studio-only diagnostic, maintenance and repair-assistance toolkit for UNA CMS. It gives administrators a consolidated view of site health, module integrity, compatibility, upgrade readiness and maintenance evidence without requiring them to hunt through server files, database tables and logs by hand.

Safety notice: Back up your website before attempting repairs or upgrades. A current verified backup protects your site if a repair, update or server problem does not go as expected.

Site Health & Diagnostics

  • Health score and severity summary.
  • UNA and PHP compatibility checks.
  • Required PHP extension verification.
  • Filesystem, database, cron and notification diagnostics.
  • Recent actionable log analysis.
  • Maintenance-state and interrupted-upgrade detection.

Module Integrity

  • Registered module and dependency checks.
  • Module file integrity and checksum analysis.
  • Compatibility declaration review.
  • Runtime-generated content detection.
  • Known-good reference comparison through the Module Reference Library.

Upgrade Intelligence

  • Awareness of UNA's configured upgrade feed.
  • Recognition of staged official UNA upgrade packages.
  • Package identity, structure and checksum validation.
  • Static inspection of supported compatibility requirements without executing staged upgrade code during a normal health scan.

Guarded Maintenance & Repair

  • Evidence-driven repair workflows.
  • Protected runtime-content handling and merge planning.
  • Maintenance controls designed to reduce accidental damage.
  • Durable repair, rollback and scan evidence for later review.

Built for UNA Administrators

My UNA Doctor keeps its workflow inside UNA Studio and is designed to make troubleshooting easier to understand without hiding the underlying evidence. Ambiguous findings are not treated as permission for blind repairs, and staged UNA upgrade code is not executed simply to determine compatibility.

A healthier UNA site starts with knowing what changed, what is healthy and what actually needs attention.

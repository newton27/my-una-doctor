SHORT DESCRIPTION
-----------------
Studio-only health, compatibility and upgrade-readiness diagnostics for UNA CMS, with guarded repair workflows, module integrity checks and protected runtime-content handling.

MARKETPLACE SUMMARY / PRODUCT INFO
----------------------------------
Know before you upgrade. Know what changed afterward. Know where to look when something goes wrong.

My UNA Doctor gives UNA administrators an evidence-driven view of site health from inside Studio. It checks UNA/PHP compatibility, required PHP extensions, module declarations and dependencies, file integrity, database consistency, maintenance state, cron registrations, filesystem conditions and recent actionable logs.

Version 0.6.6 fixes UNA installation SQL compatibility and sequential retry safety, with direct file updaters from 0.6.1 through 0.6.5. Version 0.6.5 adds reliably painted long-running activity feedback with rotating work phases and elapsed time. Reduced-motion mode uses a static indicator, and the Saved Module Reference Library supports an 80%–125% browser-local text-size preference. It retains Compatibility & Upgrade Intelligence, verified-reference safeguards and duplicate-action protection without enabling destructive reference repair.

SAFETY NOTICE
-------------
Back up your website before attempting repairs or upgrades. A current verified backup protects your site if a repair, update or server problem does not go as expected.

My UNA Doctor does not blindly repair ambiguous findings, silently rewrite third-party baselines or execute staged UNA upgrade code during a normal health scan.

STUDIO -> APPS MARKET -> DOWNLOADED -> INFO POPUP
--------------------------------------------------
This is a mandatory release requirement.

UNA 15 does not build the Downloaded-page product-info popup from this local text file, cover.jpg or install/config.php. When the administrator clicks a module in Apps Market -> Downloaded, UNA sends the module's internal name to the UNA Marketplace integration endpoint and requests the Marketplace product whose Name matches that internal module name.

For this module the required Marketplace Name is:

    my_una_doctor

Do not rename that Marketplace Name to "My UNA Doctor", "my_una_module_doctor" or any other variation. The human-facing Marketplace Product Title may be "My UNA Doctor", but the Marketplace Name must remain exactly `my_una_doctor` because that is the `name` value in install/config.php.

The Marketplace record must be published and must contain the matching current version/package. The Marketplace description and screenshots are also the content UNA Studio uses in the native product-info popup.

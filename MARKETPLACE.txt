SHORT DESCRIPTION
-----------------
Studio-only health, compatibility and upgrade-readiness diagnostics for UNA CMS, with guarded repair workflows, module integrity checks and protected runtime-content handling.

MARKETPLACE SUMMARY / PRODUCT INFO
----------------------------------
Know before you upgrade. Know what changed afterward. Know where to look when something goes wrong.

My UNA Module Doctor gives UNA administrators an evidence-driven view of site health from inside Studio. It checks UNA/PHP compatibility, required PHP extensions, module declarations and dependencies, file integrity, database consistency, maintenance state, cron registrations, filesystem conditions and recent actionable logs.

The current release includes Compatibility & Upgrade Intelligence. Doctor can check UNA's configured upgrade feed, recognize an already-staged official target package, verify its MD5 and structure, confirm target identity and inspect a limited set of literal compatibility requirements without executing target upgrade code.

FEATURES
--------
- UNA health score and severity summary.
- PHP minimum-version verification from local UNA source.
- Required PHP-extension verification.
- Registered module compatibility/dependency checks.
- Official UNA upgrade-target awareness.
- Trusted staged-package static inspection.
- Module Reference Library for known-good repair references.
- Maintenance and interrupted-upgrade diagnostics.
- Module checksum and update-readiness analysis.
- Approved compatibility-override recognition.
- Runtime-generated content detection.
- Guarded runtime-content protection and merge planning.
- Durable repair/rollback evidence.
- Database, notification, cron, filesystem and log diagnostics.
- Historical scan evidence retained in Studio.

SAFETY NOTICE
-------------
Back up your website before attempting repairs or upgrades. A current verified backup protects your site if a repair, update or server problem does not go as expected.

My UNA Module Doctor does not blindly repair ambiguous findings, silently rewrite third-party baselines or execute staged UNA upgrade code during a normal health scan.

STUDIO -> APPS MARKET -> DOWNLOADED -> INFO POPUP
--------------------------------------------------
This is a mandatory release requirement.

UNA 15 does not build the Downloaded-page product-info popup from this local text file, cover.jpg or install/config.php. When the administrator clicks a module in Apps Market -> Downloaded, UNA sends the module's internal name to the UNA Marketplace integration endpoint and requests the Marketplace product whose Name matches that internal module name.

For this module the required Marketplace Name is:

    my_una_doctor

Do not rename that Marketplace Name to "My UNA Module Doctor", "my_una_module_doctor" or any other variation. The human-facing Marketplace Product Title may be "My UNA Module Doctor", but the Marketplace Name must remain exactly `my_una_doctor` because that is the `name` value in install/config.php.

The Marketplace record must be published and must contain the matching current version/package. The Marketplace description and screenshots are also the content UNA Studio uses in the native product-info popup.
